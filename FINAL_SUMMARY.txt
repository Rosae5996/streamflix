                         TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

Issue: Can't login
Solution: Run setup script again
  $ npx ts-node scripts/setup-default-accounts.ts

Issue: Mobile layout broken
Solution: Clear browser cache (Ctrl+Shift+Delete)
  Or test in incognito mode

Issue: Videos not streaming
Solution: Verify R2 credentials in .env.local
  Check /api/video/presigned-url endpoint

Issue: Admin features not working
Solution: Verify user role = 'admin' in database
  Check RLS policies in Supabase console

Issue: Slow performance
Solution: Check browser DevTools Performance tab
  Clear local storage if needed
